# WebMCP Shared Canvas

A collaborative spatial workspace where a human and an external AI agent share context through WebMCP.

Human selections become temporary spoken keywords. The agent can resolve those references, read structured canvas content, inspect selected visuals, communicate before changing work, and leave visible results in the shared canvas.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). WebMCP tools require a compatible browser implementation.

## Supported canvas elements

- Markdown documents
- PDFs
- CSV files
- Websites
- Notes
- Images
